# Life Butler Cloud · 生活管家

基于微信云开发的个人生活管理小程序，把待办、记账、课表、随记与日常工具整合在一起，支持同一微信账号在手机与 PC 之间同步记录。

使用微信原生小程序开发，客户端无需前端框架或构建依赖；数据由云函数统一处理，存储于微信云数据库和云存储。本仓库是可独立运行与部署的**云服务版本**。

## 功能

| 模块 | 支持的能力 |
| --- | --- |
| 待办管理 | 新增、编辑、搜索、筛选、时间范围、完成状态和图片附件 |
| 到期提醒 | 用户主动订阅后，由云端定时任务检查并发送微信服务通知 |
| 日常记账 | 金额、分类、备注、任意月份账单、分类汇总与分批展示 |
| 课表与考试 | 周课表、单双周、课表文件导入、教学周校准、考试安排和倒计时 |
| 拍照随记 | 拍照或相册选图、价格、评论、编辑与搜索，可加入购物清单 |
| 生活管理 | 课程作业、物品保修、购物清单、月度预算、纪念倒数与保质期 |
| 习惯与专注 | 习惯打卡、日历补记、连续天数、番茄钟与专注统计 |
| 每日签到 | 联网同步成功后自动签到，展示签到日历与连续签到天数 |
| 借还与饮食 | 借入借出、归还状态、逾期标记、菜谱收藏、食材清单与周饮食安排 |
| 回顾与时间轴 | 周/月生活回顾、记录筛选、往年今日与回顾文本复制 |
| 搜索与备份 | 跨模块搜索、包含照片的完整 JSON 备份、预览恢复与旧数据合并 |
| 个性设置 | 主题色、深色模式、大字号、常用功能选择与排序 |

另有 **16 款计算工具**：房贷计算、单位换算、日期间隔、BMI、储蓄目标、折扣计算、随机选择、文本统计、AA 分账、年龄计算、日期推算、时长计算、油耗费用、水电估算、百分比计算和进制转换。

底部导航分为「待办」「记账」「工具」「我的」，生活管理与计算工具集中在「工具」页。

## 技术栈

- **客户端**：微信原生小程序、JavaScript、WXML、WXSS、自定义 TabBar。
- **云服务**：微信云开发、云数据库、云存储、Node.js 云函数、`wx-server-sdk`。
- **数据同步**：修订号检查、记录版本校验、请求去重、提交结果确认。
- **自动化验证**：Node.js 内置测试运行器、模拟微信客户端与云数据库、项目结构和共享模块检查。

## 快速开始

### 1. 获取代码

```bash
git clone https://github.com/Wangcongming666/Life-Butler-Cloud.git
cd Life-Butler-Cloud
```

准备微信开发者工具、自己的小程序 AppID，以及已关联该小程序的云开发环境。云函数运行环境使用 Node.js 18 或更高版本；本机开发与验证建议使用 Node.js 22 或更高版本。

### 2. 创建本机配置

首次克隆后，在仓库根目录执行以下 PowerShell 命令：

```powershell
Copy-Item project.config.example.json project.config.json
Copy-Item miniprogram/utils/cloud.example.js miniprogram/utils/cloud.js
Copy-Item cloudfunctions/lifeButler/environment.example.js cloudfunctions/lifeButler/environment.js
```

已有配置时请直接编辑现有文件，避免再次复制覆盖。

| 文件 | 需要填写的内容 |
| --- | --- |
| `project.config.json` | 将 `appid` 改为自己的小程序 AppID |
| `miniprogram/utils/cloud.js` | 将 `ENV` 和 `APPID` 改为自己的云环境 ID 与小程序 AppID |
| `cloudfunctions/lifeButler/environment.js` | 将 `ENV` 改为与客户端一致的云环境 ID |

这些本机配置文件以及开发者工具生成的 `project.private.config.json` 均被 Git 忽略，仓库只提交模板。请勿将 AppSecret、腾讯云密钥、访问令牌或私钥写入客户端或公开文档。

### 3. 导入工程与部署

1. 在微信开发者工具中导入**本仓库根目录**。配置已指定 `miniprogram/` 和 `cloudfunctions/`。
2. 在云开发控制台选择自己的云环境，创建以下集合：

   | 集合 | 用途 |
   | --- | --- |
   | `life_users` | 用户数据代次与修订号 |
   | `life_records` | 业务记录、设置与删除标记 |
   | `life_operations` | 请求去重及提交结果确认 |
   | `life_imports` | 批量导入暂存状态 |
   | `life_todo_reminders` | 订阅提醒、发送认领与结果 |

3. 按 `cloud/database.rules.json`、`cloud/database.indexes.json` 配置数据库权限与索引。客户端不能直接读写业务集合，业务访问由云函数处理。
4. 按 `cloud/storage.rules.json` 配置云存储权限，仅允许创建者读写自己的照片。
5. 右键 `cloudfunctions/lifeButler`，选择「上传并部署：云端安装依赖」。上传完整目录，包含本机填写的 `environment.js` 和 `shared/`，并将超时设置为 60 秒。
6. 重新编译小程序，在「我的 → 立即同步」检查连接，再验证新增、编辑、图片上传等操作。

客户端无需执行 `npm install` 或「构建 npm」。业务云函数的依赖由部署时在云端安装。`quickstartFunctions` 是保留的示例云函数，无需部署。

详细步骤见 [部署与手机 / PC 验收](docs/DEPLOYMENT.md)。

## 待办到期通知

未完成且未到期的待办可点击「到期提醒」，用户同意微信订阅后，云端在截止前 30 分钟内尝试发送一次通知。关闭小程序后仍可接收，点击通知可进入对应待办。

使用前需要：

1. 在微信公众平台选择适用的订阅消息模板。
2. 编辑 `miniprogram/utils/reminder-config.js`，填写自己平台的 `templateId` 和实际关键词编号，并选择对应发布状态。
3. 执行 `npm run sync-shared`，同步客户端与云端模板配置。
4. 部署完整业务云函数，确认 `subscribeMessage.send` 权限及 `todoDueReminders` 定时触发器已启用。触发器配置见 `cloudfunctions/lifeButler/config.json`，每分钟检查一次。

仓库中的模板配置仅供参考，需要根据自己的小程序后台确认。完成、删除、改期或整库替换会使旧提醒失效；改期后需要重新授权。提醒不保证秒级送达，距离截止过近才授权可能无法及时发送。

更多行为说明与验收步骤见 [部署文档第 8 节](docs/DEPLOYMENT.md#8-待办到期服务通知)。

## 多端同步

同一微信账号在同一 AppID 下共用云端记录。启动、返回前台、切换页面时同步，前台每 30 秒检查更新；没有变更时仅检查修订号。

- 普通保存等待云端确认；待办勾选先提供即时反馈，失败后回退到已确认状态。
- 同一条记录出现编辑冲突时保留草稿，需要重新打开最新记录编辑。
- 离线时可查看已加载或通过身份验证后恢复的缓存，目前没有离线编辑队列。
- 冷启动无法验证用户身份时，会显示重试入口，需要联网后继续。

## 备份与恢复

在「我的 → 备份与恢复」可生成包含照片的完整 JSON 备份。生成后请导出到小程序外保存；仅含文字与图片路径的旧式导出不能替代完整照片备份。

恢复前会展示预览并要求确认。「合并」保留独立记录并处理冲突，「覆盖恢复」则替换同一账号的云端数据，也会影响其他设备。进行中的计时不会随恢复继续运行。

项目保留旧数据迁移能力，可检查当前设备旧缓存，或选择已有完整备份后合并到云端。复制代码不会复制设备中的实际数据。

## 课表导入

支持手动录入、UTF-8 CSV、制表符文本和结构化 JSON，导入前先预览，再选择追加去重或替换。

```csv
课程名称,星期,开始节次,结束节次,周次,教师,教室
示例课程,星期一,1,2,1-16周(单),教师姓名,教学楼101
```

另外适配长春理工大学研究生系统导出的**网页型 DOC/MHTML 课表**。这是特定格式适配，传统二进制 `.doc`、`.docx`、Excel、PDF 和截图不支持直接解析。

导入后请按校历设置第一周周一或校准当前教学周。考试信息需要手动录入，不会自动登录教务系统获取。

## 开发与验证

先按上文复制配置模板，再在仓库根目录运行：

```bash
npm test
```

测试使用模拟微信客户端和数据库，不访问真实云端业务数据。修改客户端共享校验模块或提醒模板配置后，运行以下命令并重新部署云函数：

```bash
npm run sync-shared
```

文件选择、相机、微信订阅授权、真实通知送达、触控布局以及手机与 PC 的同步，需要在微信客户端单独验收。自动化测试通过不代表云端环境已部署。

## 当前边界

- 保存操作需要网络，不支持离线编辑后自动排队提交。
- 删除业务记录暂不自动物理删除云文件，以保留其他设备草稿或待确认提交可能引用的照片；确认不再使用后需整理云存储配额。
- 批量导入最多 20000 条，单条记录最多 128 KiB；超出限制会报错。
- 计算工具在本机根据输入计算，不自动获取实时利率、油价或水电价格。
