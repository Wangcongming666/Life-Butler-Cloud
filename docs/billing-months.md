# 账单月份与统计核验

记账页默认显示全部月份，按记账日期倒序展示。首次展示 20 笔，滚动到底部或点击“加载更多”再展示 20 笔，直到显示全部。同步仍获取用户的完整快照；此处是界面分批展示，切换月份和加载更多不额外请求云函数。

顶部“选择月份”使用原生年月选择器，可以查看任意月份，包括没有记录的月份。选择月份时关闭“全部月份”，重新从前 20 笔开始；打开“全部月份”恢复累计视图。同步刷新保留已展开的列表数量和月份选择。

## 统计口径

所有金额使用整数分求和后格式化，按 `createdAt`（用户选择的记账日期）归属月份，修改时间不影响归属。

| 功能 | 核验结果 |
| --- | --- |
| 全部月份 | 累计金额、笔数、分类汇总覆盖全部账目 |
| 指定月份 | 使用当地时间该月首日到下月首日的区间筛选，汇总完整结果后分页展示 |
| 空月份 | 金额为 0.00、笔数为 0，明确显示空状态 |
| 分类统计 | 按完整筛选结果汇总，金额倒序展示 |
| 月度回顾 | 原本已有总额、笔数、分类、每日支出；新增从账单月份直接进入对应回顾 |
| 月度预算 | 原本依据实际记录计算已支出和分类支出；新增按所选账单月份进入预算 |
| 新增、修改、删除 | 云端确认并刷新后重新计算；修改记账日期会改变月份归属 |
| 多端 | 另一端已确认的更改在本端完成同步后参与汇总 |

原有不足是“全部月份”仅影响明细，顶部仍是本月数据，且没有历史月份入口；此次统一明细与汇总范围，并补齐月份选择与分批展示。统计是查看时基于已有数据计算，没有新增月末定时任务或历史报表归档。
