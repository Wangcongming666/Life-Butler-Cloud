# 每日签到

- 独立于习惯打卡，按设备当地日历日期记录，一天一条；云端使用日期作记录编号。
- 前台首次同步成功自动签到；联网恢复后同步成功也会重试。云端确认后弹出连续签到天数和名言，当天后续进入不再弹出。
- 工具 → 每日签到可查看当前连续、最长连续、累计天数及每月签到日历。漏签会重置当前连续天数，不支持手动补签。
- 旧快照缺少 signins 时默认空列表；备份和云同步保留签到记录。不会计入习惯打卡统计。
